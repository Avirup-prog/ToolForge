Phase 4 is the final phase yes! And you're right about the 2 AI tools:

- **Remove Background** — uses `rembg` (AI model that runs locally on the server)
- **Upscale Image (AI)** — uses `opencv` / basic super-resolution

Both are included in Phase 4 — they're just Python libraries that run on the Render server, so they're part of the same FastAPI backend. No external AI API needed, no extra cost.

**One thing to know about Render's free tier** — it sleeps after 15 mins of inactivity, so the first request after idle takes ~30 seconds to wake up. Fine for a portfolio project, upgrade to paid later if needed.
